# Code of Conduct

## Our standard

QuotaArc is a community project built on open source inherited from others. Be
decent: be respectful in issues and PRs, assume good faith, critique code not
people, and keep discussions about the product.

## Scope

Applies to the repository (issues, PRs, discussions) and project spaces. The
maintainers may remove comments, close interactions, or ban contributors who
behave badly — including harassment, hate speech, personal attacks, publishing
others' private information, trolling, or sustained bad-fait arguments.

## Reporting

Report problems through GitHub's private contact for the maintainers (or the
security advisory channel for sensitive matters). Reports are handled with
discretion.
