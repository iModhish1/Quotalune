## AUTHORITY (DONE — the architectural decision is implemented)

- **THE formula lives in `rust/src/surface_layout.rs`** (`codexbar` crate).
  `ResolvedSurfaceLayout::compute(LayoutInput)` is the only production
  geometry algorithm. `LayoutInput::new` sanitizes everything (NaN/inf/neg
  work area → 1280×752, corrupt dpi → 1.0, user scale clamp 0.5..2.0,
  providers 1..64, unknown tokens → deterministic fallbacks).
- **Frontend receives DTOs**: `ResolvedSurfaceLayout` (serde camelCase).
  TS `src/design-system/surfaceSizing.ts` is types + total validator +
  CSS-var helper only — zero geometry.
- **Golden fixtures**: `docs/golden_surface_layouts.json` generated by Rust
  (`cargo test --lib dump_golden -- --ignored --nocapture`, then trim to
  JSON end). Pinned byte-for-byte by Rust `golden_fixtures_match_the_
  rust_authority_byte_for_byte` AND parsed by TS `surfaceSizing.test.ts`.
  If Rust changes, regenerate — never hand-edit.
- **Settings**: `taskbar_arc_scale` (75..=200, default 100) independent of
  `top_arc_scale`; migration + clamp + independence tests in
  `rust/src/settings/tests.rs`.
- **surfaces.rs**: DEFAULT_* constants DELETED. Creation = provisional size
  → `apply_surface_layout()` (authoritative) before `show()` (no flash).
  Resize contract is DATA: commands take `(state: String, provider_count:
  Option<u32>)`. Taskbar no longer reads top_arc_scale (bug fixed).
- **Coordinator**: `rust/src/surface_coordinator.rs` — SurfaceCoordinator
  state machine, at most one expanded overlay, exhaustive 5×5 test.
  `Transition` enum tells the window manager exactly what to do.
