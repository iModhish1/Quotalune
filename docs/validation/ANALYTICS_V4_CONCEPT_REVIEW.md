## Implementation contract

- Preserve the existing Quotalis logo assets, geometry and logo preferences.
- Use the original bundled provider SVGs over decorative planetary surfaces.
- Use a static cosmic background (owner separately approved the extracted art).
- Place provider instruments on a shared decorative orbital ellipse.
- Place Attention, Trend and Reset together in the desktop editorial row.
- Place a compact provider usage matrix and quality summary below the row.
- Keep raw observations, extra physical windows and detailed diagnostics in
  disclosures; preserve all source access.
- Keep theme resolution, filters, Demo isolation and metric guards intact.
- A usage-matrix dot represents an actual latest observed quota in a time bucket.
  It does not represent coverage, token consumption or a fabricated sub-day sample.
  Missing buckets stay missing; accounts and physical windows remain separate.
- The quota arc alone encodes used percentage. Globe size and orbit geometry are
  decorative. No 3D renderer, permanent animation loop or remote art dependency.
