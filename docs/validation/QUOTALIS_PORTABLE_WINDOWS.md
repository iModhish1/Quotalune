# Quotalis for Windows — ZIP edition

Extract **all** files into one folder, then open `Quotalis.exe`. Keep the supplied
icons beside the executable: the app uses them for its native identity and
notification artwork. The original Quotalis and provider logos are preserved.

This package contains the Windows x64 desktop application. It requires Microsoft
Edge WebView2 Runtime and the Microsoft Visual C++ x64 runtime. The Setup edition
can install missing prerequisites; the ZIP edition does not install them. Other
operating systems and native ARM64 builds are not included in this archive.

“ZIP edition” means no installation wizard. Settings, accounts and history still
use the normal per-user application-data location, shared with an installed copy.
They do not travel with this folder. Unzipping another copy does not create an
isolated profile. Close an existing Quotalis instance before launching this copy.

Use Demo Mode to explore without connecting accounts. Demo observations are
simulated and do not enter your real provider history. Account credentials and
personal data are not part of this download.

Download releases, report issues and read the project documentation at
