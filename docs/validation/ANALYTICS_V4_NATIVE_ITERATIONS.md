# Native cosmic Dashboard iterations

Only native Dev captures count as implementation evidence. The owner-selected
cosmic concept remains unchanged; later generated control/matrix sheets were
rejected and were not used as the new art direction.

## Iteration 1

Evidence: `native/V4_CYCLE1_TOP.png` (1216×688 CSS px).
Top differences: oversized status ribbon; dominant spend caveat; extra freshness
row; verbose trend subtitle; verbose comparison caveat; native filter; full
range button strip; oversized globes; linear reset ticks; coverage blocks instead
of a usage matrix. Repaired these in the next native build.

## Iteration 2

Evidence: `native/V4_CYCLE2.png` (1280×730 CSS px).
Top differences: select chrome inherited generic gray styling; reset grouping
stacked providers vertically; Grok dark-icon contrast; overly long statistic
labels; missing plotted point labels; repeated historical summaries; tall matrix
rows; matrix below generic disclosures; too many secondary trend controls;
large blank space caused by long copy. Repaired or progressively disclosed these.

## Iteration 3 and final corrections

Evidence: final `QUOTALIS_V4_NATIVE_OVERVIEW.png` and component captures.
Inspected: original app mark, six original provider icons, quota arc values,
decorative orbit, background texture, Attention/Trend/Reset grouping, actual
matrix observations, sidebar expansion, RTL, narrow layout. Follow-up native
checks found transparent popover bleed and light-theme status contrast: popovers
now use the opaque resolved theme core, and light surfaces have darker status
colors. RTL numeric reset bands isolate their direction. Narrow instruments
scroll in a bounded horizontal row rather than pushing all analytics below
three rows of planets. Existing usage emphasis, templates and identity resolution
are retained; the selected image does not override the user's saved semantics.

## Honest differences from the mockup

- Native Windows shell and original Quotalis mark replace the generated mockup's
  invented mark and macOS controls.
- Original bundled provider icons are preserved, including their actual registry
  artwork, rather than copying generated substitutes.
- The matrix contains actual daily observations, not eight fabricated dots per
  provider/day. Missing/unknown histories remain unavailable.
- Native 1280×730 CSS viewport requires scrolling to see the entire matrix;
  the first viewport contains live limits and analytical conclusions.
- Arabic regional date formatting continues to respect the user's existing
  setting; changing interface language alone does not force regional overrides.

These differences are disclosed rather than claimed as pixel equality. Owner
visual acceptance remains separate from engineering verification.
