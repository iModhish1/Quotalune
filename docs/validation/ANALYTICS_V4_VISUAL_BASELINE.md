# Analytics V4 visual baseline

Starting clean HEAD: `1615a09d1bc6e65fa7de1849c180653d9c254357`, September 10, 2026. Native Quotalis Dev viewport: 1280×730 CSS pixels, current Windows display. Captured real state, then the authorized golden Demo6 / connectedShowcase / seed1 / 30-day source / 7-day range. No production Dashboard code changed before this audit or the concept generation stage.

V3 engineering acceptance did not confer visual acceptance. The owner's rejection supersedes that presentation checkpoint.

| Priority | Area | Observable failure | V4 design acceptance |
|---|---|---|---|
| P0 | Hierarchy | Scope explanations and source notes compete with actual conclusions | One compact command line, one decision-oriented metric ribbon; caveats in relevant details |
| P0 | Scrolling | First viewport reaches only the beginning of trend intelligence | Real plotted trend and the reset/attention summary visible on first desktop viewport |
| P0 | Sparse/unavailable | Several statistics repeat insufficient-history language; technical account text repeats | One cohesive contextual state; show available readings and put reasons behind one disclosure |
| P0 | Tables | Current and historical tables stack; physical windows appear as equal top-level rows | One default provider matrix; expand provider to physical windows and detailed analytics |
| P0 | Controls | Native select styling and basic disclosure column picker look unfinished | One accessible, themed trigger/menu/popover grammar with tested keyboard and RTL behavior |
| P1 | Information density | Large interiors coexist with very small labels | Fewer explanatory labels, compact instruments, stronger primary numerals and deliberate row height |
| P1 | Chart composition | Fixed 0–100 range leaves the plotted data near an empty floor | Clearly labeled adaptive trend domain, observed extrema, current value and contextual comparison |
| P1 | Analytical language | “Account identity unresolved” and provenance read like a debug report | User-facing summary such as “Account details unavailable”; exact diagnosis remains accessible |
| P1 | Table typography | Wide columns, repeated unknown text and equal emphasis across fields | Essential columns first, tabular numerals, compact statuses and optional diagnostics |
| P1 | Section rhythm | Many similar top rules without strong differences in purpose | Shared instrument rail, analytical canvas, compact reset band, operational matrix and quality footer |
| P1 | Typography | Labels are uniformly tiny while values are abruptly large | Explicit title/value/body/meta scale; meaning does not depend on a forest of microcopy |
| P1 | Empty space | Few-provider and narrow states stretch or stack large structures | Sparse data adapts intentionally; secondary views collapse instead of reserving chart-sized shells |
| P1 | Material hierarchy | Dark rectangles with hairlines are the dominant visual grammar | Bounded structural surfaces, restrained metallic accent, lighter analytical hierarchy without card nesting |
| P1 | Data Quality | Date spans, counts, heatmap and source diagnostics form another large page | Concise coverage/freshness/identity summary; deeper provenance behind “Data details” |
| P1 | Reset Horizon | Staggered Now/2h/0.5h labels interrupt natural order; markers look prototype-like | Chronological calibrated grouping with explicit elapsed-time labels and readable event scope |
| P1 | Current Limits | Arc, large numbers and secondary rails occupy too much height | Refined calibrated gauge, clear used/remaining pair, one reset index and compact secondary windows |
| P2 | Context/advanced detail | Raw readings are useful but too easy to mistake for primary analytical content | Explicit advanced disclosure and scoped chart/table tools, with keyboard-accessible alternatives retained |

## Factual design inputs

- Actual sidebar: Monitor (Dashboard, Usage & Spend), Workspace (Providers, Workspace with Profiles/Collections), expandable Settings with existing destinations. Do not invent new product modes.
- Demo providers: Codex 68% used / 32% remaining; Claude 42/58; Gemini 81/19; Perplexity 34/66; DeepSeek 73/27; Grok 57/43. Near-time resets are relative and continue ticking; illustrative concepts must label themselves as design targets.
- Example validated Claude physical-window observations: 33.5, 34.9, 36.3, 37.7, 39.1, 40.5, 41.9%. Mean 37.7%; change +8.4 percentage points. Prior comparable observations are 9.8 points lower. These are quota states, never token/revenue consumption.
- Eight physical Demo window series × seven selected daily observations give 56 capture samples. Evenly observed cells remain even; do not invent a noisy heatmap for aesthetics.
- Real Dev is sparse: Codex readings and Claude requiring sign-in. The sparse layout must remain intentional.
- Preserve registry, physical window/account/currency guards, unknown-vs-zero distinction, existing theme resolver, provider identity and lazy ECharts lifecycle.
